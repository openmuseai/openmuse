# 代码导航与语言扩展：首期产品规格

日期：2026-11-17。方案依据当前插件市场、统一资源中心、独立 LS 内核与双端 Viewer；实现和实测结论在验收记录中分别标记。

## 三个市场条目

| 稳定身份 | 交付物 | 依赖和目标 |
|---|---|---|
| `com.openmuse.code-navigation` | 独立 Node 内核、stdio backend、vscode-jsonrpc、许可证 | 无语言依赖，安装到资源宿主 |
| `com.openmuse.code-navigation.dart` | Dart 语言 profile | 依赖服务；使用宿主已有 Dart SDK |
| `com.openmuse.code-navigation.typescript` | TS/JS profile、锁定 TypeScript 5.9.3 和 typescript-language-server 6.1.0、许可证 | 依赖服务；不依赖用户 npm 全局安装 |

首期 catalog/归档随正常应用进入 curated market。每个条目有独立版本、依赖、完整文件摘要及安装 receipt；不是三个开关指向同一份无校验的隐藏全局配置。远端公共 registry 的发布需要独立发行流程，不能把本地 catalog 验收称为线上公共服务已发布。

Mobile 显示“已连接 Desktop”，安装在 Desktop；本机不下载/启动 LS。Desktop 显示“当前 Desktop”。之后扩展其他资源宿主时，同一管理能力由其执行 Provider 提供，不让手机理解宿主目录。

## 市场与配置页面

市场卡片显示：名称、版本、语言/能力、安装目标、当前安装/启用状态、“安装与配置”。语言扩展页提供“安装依赖：代码导航服务”按钮，用户明确安装依赖后再安装语言插件，不在错误重试中暗中下载。

```text
< Dart 语言扩展                                  刷新
安装与配置目标：已连接 Desktop
已安装 · 已关闭 · 待检测 · 运行实例 0

宿主 Dart 可执行程序路径
[/path/to/dart-sdk/bin/dart                      ]
初始化选项（JSON）
[{ "onlyAnalyzeProjectsWithOpenFiles": true }   ]
语言服务设置（JSON）
[{ "dart": { ... } }                           ]

[保存配置] [检测配置] [启用插件] [卸载插件]
```

TS/JS 页面显示随插件安装的固定服务版本，配置初始化选项和语言设置；服务页配置空闲释放（30–3600 秒）与实例上限（1–4，默认 2）。常用配置用表单，结构化语言设置可编辑 JSON；非法 JSON、未知配置字段和越界值拒绝。

首期启动模板由语言插件固定。Dart 的参数固定为 `language-server --protocol=lsp`；TS/JS 使用受管 Node 与随插件安装的 LS/tsserver 路径。暂不提供任意 shell 字符串、自定义环境变量或其他语言执行模板。TS/JS 自动 typing acquisition 固定关闭，tsserver 固定 semantic 模式，避免隐式下载与错误首跳。文件关联由对应 profile 声明，TSX/JSX 使用相应语言 ID。

配置保存会停止旧实例、关闭该插件、使语言检测状态失效；检测通过后重新启用。不同设备同时编辑时，以 configuration revision 拒绝旧配置覆盖，页面提供刷新。SDK/程序路径不复制到手机目录；不将路径当作资源身份。

## 状态与可观察行为

| 状态/动作 | 用户可见结果 | 语言进程 |
|---|---|---|
| 未安装 | 安装入口 | 0 |
| 安装成功 | 已安装、已关闭 | 0 |
| 配置保存 | 待检测，提示重新检测 | 旧实例已停止 |
| 检测 | 局部进度；实际 initialize + 定义查询 | 临时启动，结束后清理 |
| 检测失败 | 可理解原因；不能启用 | 无残留，否则不能报告成功 |
| 启用 | 已启用、按需启动 | 0，直到第一次查询 |
| Viewer 工作区开启 | 保存该宿主工作区策略 | 不预热/全库索引 |
| 首次符号查询 | 底部候选，统一资源引用打开目标 | 按账号/代际/工作区/语言复用 |
| 关闭 | 等待释放；成功后已关闭 | 所属实例组退出 |
| 卸载语言扩展 | 删除私有交付物、配置与启用状态 | 先退出，再卸载 |
| 卸载服务 | 有语言依赖时拒绝并说明；否则删除服务及工作区策略 | 0 |

检测失败不能标记为可用；停止失败不能标记已释放；返回源码不能重置视口。禁用、卸载或换账号后的迟到查询结果不能更新页面。诊断不记录源码、密码、环境变量或完整程序输出。

## 验收范围

双端使用同一国内账号，Android 使用实际连接设备，均保留正常版。分别验证三个条目安装、配置保存及检测，启用后零实例，真实 Dart/TS 跨文件函数/方法定义，中文路径、行定位和返回；至少一次由手机管理后 Desktop 刷新看到同一状态。验证关闭释放、依赖卸载拒绝、按序卸载、重新安装与账号隔离。

自动化验证摘要不符/额外文件、错误 SDK、旧 revision、任意操作拒绝、直接代理私有管理路径拒绝、授权失效、无进程残留；真实语言检测和 UI 测试分别计数。国内端到端冷/热 P95、RSS/CPU 仍须单独采样，单次功能通过不代表这些指标已达标。
