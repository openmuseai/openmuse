# 可选代码导航服务：产品稿

日期：2026-11-15。状态：产品与技术方案已定，按 PLAN 分阶段实施；不是已发布功能说明。

## 用户价值与边界

在 Mobile / Desktop 的 open-file-viewer 中点击函数、类型、变量，预览定义并打开目标、查找引用和实现。代码解析在资源宿主执行，Mobile 不拼接宿主文件路径、不运行语言服务器。关闭语言服务仍保留 Tree-sitter 高亮、文本选择、文件链接和行号定位。

语言服务是独立、可选的插件服务。与 DSH 的关系是资源适配，不是父子业务依赖；其他本地目录、容器和云端资源源都能提供适配器。启用范围为当前账号在指定资源宿主上的 workspace，不因切换会话启动新进程。

## 设置稿

入口：插件中心 → 代码导航 → 当前资源宿主。

```text
代码导航                         [关闭 ○]
在资源所在设备分析代码，支持定义、引用和实现。

运行方式：按需启动
空闲释放：5 分钟
最大语言进程：2
查询超时：5 秒（首次启动最长 15 秒）

语言支持
Dart                 未配置
TypeScript/JavaScript 可用

运行实例
Workspace A · TypeScript · 空闲      [停止]

[停止全部]   [查看诊断]
```

默认关闭；打开开关仅保存策略，不立即启动语言进程或索引。用户第一次查询才启动对应 workspace / 语言实例。设置改变只由所属宿主确认后生效；Mobile 显示“等待宿主确认”，不能乐观宣称停止成功。停止全部清空实例并回到已启用但未启动状态；关闭开关同时取消排队和运行中的请求，等待进程退出。

只允许选择已注册语言配置，不允许通过远端请求提交 command / args / env。安装或下载语言服务是独立操作，不在点击代码时自动下载。首期按宿主实测支持 Dart、TypeScript/JavaScript，未配置时显示原因。

## 代码阅读稿

```text
< 示例.dart                  [符号目录] [更多]
120  final result = repository.load(id);
                    ^ 点击 load

┌ load(id) ────────────────────────────┐
│ 定义 · lib/repository.dart:42        │
│ Future<Result> load(String id) ...   │
│ [打开定义] [查找引用] [查看实现]      │
└─────────────────────────────────────┘
```

单击符号打开底部预览面板；长按保留选择复制，并增加导航菜单。定义唯一也先预览；多结果显示相对路径、所属类型和代码摘要。明确文件链接可直接打开。点击“打开定义”沿用统一资源打开流程，精确定位符号范围；返回恢复原文件纵向/横向位置和选择状态。查找引用分页展示，不一次加载全部文件。

服务关闭：面板显示“代码导航未开启”和当前宿主的启用入口；无权限则不显示可操作开关。初始化显示局部进度，源码可继续滚动。无定义、语言未配置、源文件已变化、宿主离线、超时、资源额度不足分别展示；取消不弹错误。搜索回退明确标为“搜索候选”，不能冒充精确定义。

## 功能验收标准

F1：默认关闭时，应用启动、打开源码、滚动、高亮均不生成 LSP 子进程。

F2：同账号/宿主/workspace/语言配置复用实例；不同账号、授权代际、workspace 不共享。

F3：定义、引用、实现、hover 由服务能力发现决定。文件目录符号和文档链接为独立能力，不能由高亮语言数量推断。

F4：中文路径、空格、emoji、UTF-16 列位置、Location / LocationLink、多结果正常；源码版本变化拒绝旧坐标查询，授权撤销后不展示结果。

F5：运行中关闭服务，取消运行和排队请求；迟到结果不能更新页面；停止失败必须显示故障，不能显示已释放。

F6：历史快照只有匹配版本的索引/服务才能精确导航；无文件上下文的对话代码块只提供搜索候选。

F7：目标经资源宿主独立授权并转换成统一资源引用，包含目标版本与范围；依赖或虚拟文件不能通过裸 URI 绕过授权。

## 性能与资源指标

指标均为发布目标，须以实际测量填写，不把默认参数或测试替身当成已达标数据。

| 场景 | 初始目标 / 默认限制 | 测量口径 |
|---|---|---|
| 关闭状态 | 0 个 LSP 进程，0 个 LSP 定时采样任务 | 启动与打开 10 个源码文件后检查 |
| 本地触摸反馈 | P95 ≤ 100ms | 指针抬起到符号/面板反馈，OPPO release |
| 热查询 | P95 ≤ 500ms | 已初始化，国内真实连接，点击到预览首帧；单独记录 RTT |
| 冷查询 | P95 ≤ 5s；15s 硬截止 | 新进程、固定规模 workspace，包含 initialize |
| 查询 | 5s 截止，超时取消并回收不响应实例 | 包含排队、读取、查询、目标授权 |
| 实例 | 每宿主默认最多 2 个受管实例 | 实例一一对应语言服务器进程组 |
| 并发/排队 | 每实例串行，全局最多 8 个请求 | 超过立即返回 BUSY，不无限堆积 |
| 空闲回收 | 默认 5min；到期后 1s 内开始停止 | 从最后请求完成计时，活动查询不回收 |
| 停止 | 2s 优雅窗口，随后强制停止；目标总计 ≤ 3s | 同时检查后代进程退出 |
| 源文件/结果 | 1MiB UTF-8 / 最多 100 个位置 | 大文件不阻塞阅读，结果标明 truncated |
| 内存 | 首期观测单实例/进程组 RSS，目标总计 ≤ 512MiB | 语言/仓库分别测量；硬限制需 OS/容器能力，不伪装成 JS 可保证 |
| 空闲 CPU | 目标进程组平均 ≤ 1% 单核 | 热查询后 60s；超标提示或回收 |

基准固定记录设备、版本、仓库 commit、文件/LOC、语言服务器版本、冷/热、网络 RTT、30 次以上样本的 P50/P95/最大值。服务关闭、空闲回收、故障及进程残留必须单独验收。
