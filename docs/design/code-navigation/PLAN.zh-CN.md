2026-11-16 更新：已实施 M2 的通用契约/RPC 与 DSH 本地 owner adapter，M3 的 Viewer 开关/符号点击/导航栈，以及 M4 的国内 Desktop + OPPO 指定 UI 路径。未完成部分继续保留为门禁，详见 [验收记录](ACCEPTANCE-2026-11-16.zh-CN.md)；以下初始计划与 M1 记录保留时间背景。

## 工作区整理

工作区有大量并行成果：文档分类迁移、协作编辑、云工作区、发布及语言文件。不能将它们混入代码导航提交。此前资源定位、Tree-sitter、DSH bridge、Viewer 插件与 source adapter 按功能分别提交；SDK 混合文件仅暂存相关补丁。其余改动保留。基础集成接线仍有未提交工作，不能把这些提交称为完全干净的发布基线。

## 分阶段交付

| 阶段 | 内容 | 验收 |
|---|---|---|
| M0 | 产品稿、指标、架构和实施计划落盘 | 边界、默认值、验收目标与当前事实一致 |
| M1 | 独立可选服务、owner seam、受限实例池、标准 stdio backend、进程清理 | 默认零进程、惰性复用、限流、取消/超时、空闲/关闭、版本/授权与真实语言 smoke |
| M2 | Resource Hub/SDK 可选能力、RPC、DSH 及挂载目录 adapter | source/peer/generation/目标授权与版本测试；不接受远端命令/路径 |
| M3 | 独立插件设置 UI、Viewer 点击预览/范围定位/历史恢复 | Flutter 交互、可访问性、中文/emoji 坐标、禁用/离线/多结果 |
| M4 | 国内 Desktop + OPPO 正常版 E2E 和性能报告 | 产品稿 F1–F7 及冷/热/停止/内存/CPU 指标；保留正常版 |

本轮先落盘 M0，随后开始 M1。每个可审查阶段单独提交并记录实际通过范围；未完成的 M2–M4 不宣称通过。不修改当前手机与 Desktop 的正常安装。

## 2026-11-15 实际进展

- M0 已落盘并提交 `a176fe8d`。
- M1 服务内核、真实 stdio backend、受限实例池与测试已提交 `50bf7f5f`。21 项状态机/真实 subprocess 测试及 1 项真实 TypeScript 语言服务测试通过；测试替身与真实语言能力分别计数。
- 真实语言测试覆盖中文跨文件定义、引用、hover、emoji 前缀后的 UTF-16 坐标、热进程复用。TypeScript profile 固定 tsserver 路径、关闭 automatic typing acquisition，并选择 semantic 单服务模式。默认 auto syntax 模式曾只返回 import 声明，未作为跨文件成功计入。
- 停止测试包含无响应服务器、语言位置编码不兼容、父进程退出后遗留 worker，以及停止失败可见/可重试。修复 macOS 空进程组 signal 误报：先验证进程组存活，再发送终止；真实存活组的权限错误仍作为失败报告。
- M2–M4 尚未实施：服务未注册到现有应用默认装配；没有设置 UI、Mobile 符号点击或真实资源 RPC 接线。本轮未安装或改动手机/Desktop 正常版。
- 详细记录与基准见 [实施记录](IMPLEMENTATION.zh-CN.md)。
