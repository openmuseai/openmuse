# 插件市场与 Mobile 页面设计对照

日期：2026-10-16。对照 [设计基线](DESIGN-SPEC.zh-CN.md) 中的 Desktop、Mobile 发现、工作台和我的概念图。Desktop 现状依据 macOS 原生集成测试中的 Flutter 渲染截图，以及当前 Debug 构建的前台应用窗口；Mobile 现状依据当前 Flutter 实现、组件测试、Android 14 模拟器截图及 Android 16 真机 UI 核对。概念图中的示例数据不作为功能验收数据。

| 页面 | 截图/代码与设计稿的差异 | 本次处理 | 尚需核对 |
| --- | --- | --- | --- |
| Desktop 市场入口 | 原实现是居中的 960×650 模态弹窗，背景工作区被遮罩；设计稿是占据窗口的独立浏览界面。 | 完整路由页面；已在当前 Debug 构建中从登录页进入匿名工作区，点击左下「插件」打开市场，关闭后回到工作区。 | 窗口手动缩放仍未复核。 |
| Desktop 导航 | 原实现只有顶部「发现/已安装」tab，没有 App Store 式左侧导航。 | 宽窗侧栏与窄窗图标栏；探索和四个类别同步筛选；顶部快速搜索点击聚焦右侧搜索框，macOS ⌘K、其他桌面 Ctrl+K 也可聚焦；底部「我的插件」及返回工作台可用。 | 当前没有独立「更新」页或可供市场使用的账户摘要；不以假数字、假身份填充。 |
| Desktop 内容 | 原顶区重复「插件市场」标题，类别用药丸，精选只有 190–250px 且浅色字层级与设计稿相反。 | 大标题，类别文字加下划线且搜索在其右侧；精选随窗口高度调整，深色渐层与白字，主按钮直接安装；推荐卡有真实目录对应的媒体。搜索和分类无结果可清除筛选。 | 设计稿中的建筑渲染图并非当前目录素材；实际 Archify 图仍是已有纸张摄影。打包目录仅有一个已验证商品，不能补造第二张可安装的编辑卡。 |
| Desktop 我的插件 | 原固定高度将已安装 Archify 卡片截断，分隔线穿过卡片，下面的内置插件单独滚动。 | 市场安装和内置插件改为整页连续滚动；重建后在真实前台窗口确认 Archify 版本、平台、状态全部显示，向下滚动可见内置插件，侧栏固定。 | 当前前台配置的 Archify 已安装且启用；未在用户配置上反复启停，安装生命周期由隔离原生测试覆盖。 |
| Mobile 发现 | 顶部双 tab、搜索在类别上方、五个类别和四项底栏已符合结构；精选只有 220dp 且没有明确操作，原代码还可能用任务看板图片介绍别的插件。 | 精选增至 300dp 并增加「查看插件」按钮；精选图片绑定到目录条目的真实素材，无媒体的详情用中性插件占位；保持跟随全局主题。 | 目前目录媒体不足，信息流的专题、视频/动图首屏表现尚不能完整复现概念图；需要真实媒体条目。 |
| Mobile 发现内「我的」 | 原分段缺「更新」，也缺工作台管理入口。 | 增加更新筛选和「工作台展示」入口，转到工作台；安装、启停、移除仍读设备实际状态。 | 概念图中的卡片缩略预览尚未在此页复用 A2UI renderer。 |
| Mobile 工作台 | 当前为真实插件贡献的 A2UI/Flutter 卡片，支持两列、pin、排序与详情 WebView；概念图使用了示意任务和用量。 | 补充编辑态高度/列宽覆盖、取消/完成持久化，以及停用插件的占位和管理入口；把编辑控件移到底部以保留标题。 | 当前预置插件数量与媒体少于概念图，视觉密度不同；真机编辑手势仍待核对。 |
| Mobile 底栏「我的」 | 原标题左对齐且大于概念图；账户、主题与插件入口存在，部分参考设置项没有领域能力。 | 标题改为居中；保留真实账户、主题和设备状态。 | 通知、存储等能力未接通前不展示假设置；需补真实领域实现后再补齐分组。 |

## 验证口径

- Desktop：[发现渲染截图](acceptance-desktop-discover-current.png)和[我的插件渲染截图](acceptance-desktop-discover-current-installed.png)来源于 macOS 原生集成测试的 Flutter surface，截图尺寸 1280×760。前台应用另以 `flutter build macos --debug --no-pub` 构建并启动，走通「匿名模式 → 工作区 → 插件 → 市场」；现场验证分类空态、快速搜索与清除、Archify 详情、我的插件完整卡片和整页滚动，以及关闭后返回工作区。Widget 测试覆盖宽/窄窗、类别/搜索相对位置、⌘K 聚焦、详情、卡片与分隔线位置；隔离原生集成测试覆盖安装、禁用/启用，并核对 DSH profile、skill 与组合配置。截图文件为测试渲染证据；前台窗口的操作通过 UI 树与实时截图复核。
- Mobile：发现/我的插件、主题、窄屏、工作台卡片与布局由 Widget 测试验证；Android 16 真机核对导航、深色发现、重启后偏好与工作台编辑控件，随后恢复原浅色偏好。读屏、动态字号和真实拖动手势仍需复核。
- Android 14 模拟器正式应用截图：[发现浅色](acceptance-android-discover-current.png)、[发现深色](acceptance-android-discover-dark-current.png)、[我的深色](acceptance-android-my-dark-current.png)、[工作台深色](acceptance-android-workbench-dark-current.png)、[工作台编辑深色](acceptance-android-workbench-edit-dark-current.png)。浅/深切换后系统栏与页面一致；编辑控件移到底部后卡片标题完整。
- 设计图只定义布局与视觉意图。插件名称、权限、平台、安装状态和媒体以目录与 manifest 为准；缺少后端来源的统计数字不展示。
