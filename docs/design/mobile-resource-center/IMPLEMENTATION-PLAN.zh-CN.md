# 多端资源中心开发与验收计划

2026-11-01。用户已授权按“共享框架、端适配”原则设计、开发并做端到端 UI 验收。此文件跟踪真实实现与证据，未执行的检查不得标通过。既有未提交代码保持原样，不自动提交或发布商店。

## 架构与交付边界

1. 纯 Dart 共享核心：稳定源/资源/版本身份、Provider/目录、精确版本读取、能力/路由、最近事件、引用剪贴板、对话绑定、创建/改名/编辑与回执。复用 Resource v1 descriptor，不修改冻结 wire。
2. 独立 IO adapter：应用管理的本机资源、持久版本、受限临时投影、PC/手机授权交接与重连、持久对话副本。路径仅存在私有 adapter，不写入跨端对象。
3. SDK 的可选共享插件能力：打开与创建贡献、平台/probe、运行时生命周期。旧 manifest v2 不增加未协商字段；无新能力的旧插件保持原行为。
4. 共享 Flutter 资源中心/引用控件，Mobile Home 和 Desktop 入口使用同一控制器/状态/路由；平台文件导入和 OS 剪贴板各自适配。
5. 真正接入 Tasks/PC 执行：引用 pin 版本，明确任务读取授权，PC UI 可重开；手机在线按需重新取，离线有合法副本才打开。保留副本是明确选项，默认仅引用，不默默长期托管或上传云。

范围包含：最近/本机/PC Workspace 目录、打开方式、引用/路径复制、重命名、插件创建、聊天资源卡片、精确版本与临时目录清理后的行为。Cloud 浏览、批量移动、永久删除、任意格式原生引擎和商店发布不在本批。

## 开发顺序

| 阶段 | 结果 | 完成门槛 |
| --- | --- | --- |
| R1 | 共享核心与本机 IO Provider | stable refs、历史版本、CAS、目录、路径隔离及持久恢复测试通过 |
| R2 | 授权远程 Provider / handoff | 复用配对身份，正反方向版本读取、过期/断开、快照、临时投影验证 |
| R3 | SDK 与真实资源插件 | 可动态注册/停用 handler/creator，创建/编辑由插件提供，Host 无类型白名单 |
| R4 | 双端入口与共用 UI | Mobile 五栏 Home，Desktop 资源入口，共用目录/打开/新建/菜单与版本状态 |
| R5 | 对话引用与执行 | 草稿卡片、pin 版本、会话授权、PC 临时内容、引用重开，不以假回调替代发送 |
| R6 | UI E2E 与构建恢复 | macOS/Android/iOS 真实 UI，网络和离线矩阵，保存可核对证据并恢复主入口 |
