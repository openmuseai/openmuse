# Home 资源中心 · 产品与交互稿

**状态：待人工审核，未批准实施。** 日期：2026-11-01。目标：OpenMuse Mobile（Android / iOS）。本稿和原型均为设计提案，示例文件、设备、插件贡献与打开结果不是真实运行数据；本轮不修改 App、不安装插件、不连接设备或发布服务。

这里的目标平台限定的是 Home 页面与交互；资源身份、插件打开/新建/编辑贡献、跨端引用与离线可用性应是多端框架能力。手机文档供 PC 任务使用、临时副本清理与离线点击的补充约定见 [多端资源引用与可用性草案](../../RESOURCE-REFERENCE-AVAILABILITY-AND-HANDOFF.zh-CN.md)。原件、对话所用版本与临时目录分别管理，不能因统一 Ref 就承诺源离线时一定能打开。

## 1. 产品定位与一级导航

Home 是所有资源的入口：找回刚才打开的内容、浏览本机或电脑 Workspace、交给本机插件处理，再将同一个资源引用带进任务。资源来源、格式、存储位置不决定它能否进入 Home。

底栏扩展为 **首页 Home / 任务 Tasks / 工作台 Workbench / 发现 Discover / 我的 Account**，五项等宽。工作台继续承载插件工作面板，发现继续负责发现和安装插件；Home 不替代两者，也不塞入推荐广告、会员横幅或第二个聊天输入栏。

- 建议普通冷启动进入 Home → 最近；通知、资源深链与恢复中的编辑器优先恢复目标。第一次升级不丢任务草稿和原有导航状态。
- 再点 Home 保持当前分栏和目录；只在列表顶部再次点选当前分栏时回到列表顶部。退出再冷启动默认最近。
- 五项底栏保留可辨识的空心图标，以颜色和短线表示选中，沿用上一批界面。长英文 Workbench 不换行，最小 11sp；320px 宽仍需完整显示。
- 只有 Home 资源列表层显示右下角 `+`。编辑器、聊天、权限页和新建面板不叠加第二个 `+`。

## 2. 首期范围

| 能力 | 首期 P0 | 不纳入首期 |
| --- | --- | --- |
| 最近 | 同一设备、当前账号下所有成功打开的资源；本地、PC、URL 同一列表；以协议引用识别，不按格式建白名单 | 最近记录跨设备同步、Cloud 浏览独立分栏、收藏与推荐流 |
| 本机 | OpenMuse 资源目录、已导入/明确授权的系统文件；按目录浏览、导入、文件夹、新建、重命名 | 扫描手机全部磁盘/相册、后台索引全部外部提供商 |
| 远程（PC） | 账号设备 → Workspace → mount → 目录；按层级分页浏览、当前 Workspace 搜索、只读或授权操作 | 任意电脑根目录、SSH 路径访问、自动打开远程电脑上的应用 |
| 打开 | 统一描述与路由，选择本机已安装、已启用且实际可用的 handler；打开方式及默认方式 | 把每种文件格式写死在 Home；下载原生 Dart/二进制代码执行 |
| 联动 | 单资源复制引用、粘贴/添加到聊天草稿、可点的引用卡片；复制逻辑资源路径 | 多选批量移动、跨来源剪切、自动把附件上传给模型 |
| 新建 | 安装插件动态贡献可创建类型；Host 负责位置、权限、名称、事务与结果；导入与文件夹为基础动作 | Host 硬编码 Word/PPT/PDF 按钮；未安装插件的假入口；模板市场 |
| 重命名 | 本机可写资源；PC 在源端 mutation/receipt 能力补齐并验收后开放同一交互 | 仅修改列表缓存、根据 filename 拼接远程绝对路径 |

**实施门槛：** PC 只读浏览已有基础，写操作不是现成能力。设计包含 PC 重命名目标；交付时若未完成该源的能力契约和验收，必须明确标只读，不能以能点击的假按钮代替。URL、视频等可以先进入列表、复制和路由；实际打开取决于可用 handler。协议不支持的解码能力不可由界面承诺。

## 3. 页面与列表规则

### 3.1 Home 公共结构

上方左对齐标题 Home / 首页，右侧搜索入口；下方横向分栏 **最近 Recent / 本机 This Device / 远程（PC）Remote (PC)**。分栏保持一行，可适度缩字并左右滑动，沿用 Discover 的导航语言；未来增加来源不用重排为多行。内容区不叠加一排常驻文件类型分类，筛选放入搜索页的筛选按钮。

列表每行包含 40px 图标/可用缩略图、最多两行名称、来源和逻辑位置、一项上下文时间、44px 更多按钮。来源直接可见：`本机 · 文档`、`工作电脑 · 产品设计 / 资料`、`网页 · example.com`。同名文件靠来源和目录区分，不靠文件名生成身份。不展示不可信的缩略图脚本或自动播放视频。

点击行打开；长按 450ms 打开同一更多菜单，轻触反馈；移动超过 10dp 取消长按并正常滚动。更多按钮、屏幕阅读器动作和桌面原型右键提供等价入口。没有依赖悬停的操作。

### 3.2 最近：默认列表

- 按 **最后一次成功打开时间** 倒序，分今天、昨天、近 7 天、更早；不限 7 天窗口。没有人为热度、协作头像或下载量。
- 记录点是路由返回 `opened` 且编辑器已建立有效资源会话；点击、下载失败、打开方式面板、预取都不计一次打开。创建后自动打开成功也进入最近。
- 去重键：当前账号范围 + provider/source 作用域 + WorkspaceRef + MountRef + ResourceRef。URL 由 URL Provider 分配资源身份，不能用标题、裸 URL、短期 grant 或下载路径做全局键。
- 保存稳定引用、展示快照、来源、lastOpenedAt、lastOpenedRevision 与可选 lastHandler；不保存 bearer、配对 cookie、临时 HandleRef 或签名下载 URL。
- 默认再打开当前版本；上次打开版本只作历史提示。重命名后同一条记录更新名称，不重复新增。已删除或权限失效仍保留记录，并提示“资源不可用 / 重新授权 / 从最近移除”。
- 首期本机持久化最近 200 条、最多 90 天，按较先达到者清理；离线不删除目录/记录，不把元数据缓存当可打开的内容缓存。
- 本机未登录也可用，单独游客命名空间。登录后不自动合并游客资源与账号记录；用户明确选择“保留本机资源”才归入当前本机目录，远程权限始终重新核验。退出时清除该账号最近/剪贴板/授权缓存，保留用户本机文件。

### 3.3 本机

“本机”指手机，不是当前选中的 PC。默认展示 OpenMuse 的资源目录及已授权位置。系统文件选取/导入由平台 Provider 接管；不把手机 `file://` 或 Android `content://` 原样作为可跨设备读取的资源身份。

首期优先“导入文件”为应用管理副本，明确显示副本归属；平台支持持续授权的文件/目录可作为来源接入，但需可恢复授权。资源条目因权限失效显示“重新选择文件”，不能后台绕过系统授权。目录页有面包屑和返回；返回先退目录，再退出 Home。

### 3.4 远程（PC）

1. 顶层按已授权 PC 分组，每个 PC 下列出其 Workspace，不合并不同 Workspace 的同名文件夹。未登录显示登录；无 PC 显示连接电脑；离线保留已知 Workspace 并标离线。
2. 进入一个 Workspace 后先展示它的 mounts。只有一个 mount 可直接展开；多个 mount 不虚构共同物理根目录。层级为 `电脑 / Workspace / mount / 目录`。
3. 每次只请求当前目录的一页（默认 100，最大 200）；按需加载，不递归扫描 PC。文件夹优先，名称自然排序；同目录排序固定，分页不能丢项或重复。
4. 面包屑中间折叠但保留末两级，点上级可跳回；Android 系统返回、iOS 导航返回行为一致。切换 PC、Workspace 或账号使旧 generation 的请求失效，不能把旧响应混入新目录。
5. Home 的浏览位置独立于 Tasks 当前执行 Workspace。浏览、复制、打开文件不会悄悄改变对话的执行电脑或目录。
6. 源 PC 离线、grant 失效、资源已移动分别显示“电脑离线”“需要重新连接”“找不到资源”，不统称网络错误。重连后重取引用映射；现有短期 nodeRef 不冒充长期 ResourceRef。

### 3.5 搜索和空状态

最近搜索仅当前账号的最近元数据；本机只搜索已授权位置；远程明确标注当前 Workspace 范围。首期不提供跨所有电脑的全文搜索。输入保留，支持清除；搜索无结果与没有资源是两种状态。

| 状态 | 主要呈现 | 动作 |
| --- | --- | --- |
| 首次最近为空 | “打开过的资源会出现在这里” | 浏览本机 / 连接电脑 |
| 本机目录为空 | “这里还没有资源” | 新建 / 导入文件 |
| PC 离线 | 目录位置保留、离线说明 | 重试 / 返回电脑列表 |
| 加载 | 与行等高的骨架，分页尾部小骨架 | 首屏不闪空状态 |
| 无 handler | 文件名、类型、来源 + “本机还没有可用的打开方式” | 查看兼容插件 / 复制资源 |
| 缓存旧内容 | 标明“离线副本 · 上次保存时间” | 只读打开 / 连接源更新 |
| 下载或打开失败 | 可取消、可重试，保留原目录和滚动位置 | 不自动连续重试或写入最近 |

## 4. 点击打开与长按菜单

### 4.1 统一打开链

`资源引用 → 源端重新授权/describe → MIME 与格式探测 → 本机能力候选与 policy → 选择 handler → materialize → 插件会话 → opened → 写最近`。

Host 使用框架资源路由，MIME/探测优先，扩展名仅作辅助；不在 Home 写 `if pptx / pdf / jpg` 的业务分发。`OpenMuseResource` 是当前 UI/编辑器桥接对象，不足以单独承担跨源身份；需要把 Resource v1 descriptor/ref 上下文一路保留到会话。

- 已有有效默认方式且 probe 可用：直接打开；只匹配一个可用 handler：直接打开；多个无默认：原生“打开方式”底部面板。
- 列表只列本机兼容、启用、收据有效且 probe 通过的插件；支持“只读”时明确标注，不静默把编辑降级为预览。匹配但不可用项可在面板下方说明原因，不能伪装可点击。
- “仅此次”不改默认；“始终使用”按账号、媒体类型、格式/意图保存偏好，不按来源路径保存。卸载/停用或版本不兼容即失效并回退选择器。
- URL 只接受 URL Provider 支持的 `https/http`；不执行 `javascript:` 等协议。无本机插件时可以明确选择“在系统浏览器打开”；不后台抓取网页或把 URL 直接发给模型。
- 远程文件使用本机插件消费受限 materialization。现有 Mobile 整包读取上限 64 MiB；超过时给“当前连接不支持此大小”，不能无限读入内存。视频先支持引用；远程流播放需要 Range/seek 与兼容播放器独立验收后开启。
- 编辑中的未保存内容仍由既有 draft/commit 机制管理；返回 Home 不擅自丢弃或覆盖。打开过程中可取消，不把取消计作错误或打开成功。

### 4.2 资源菜单

| 菜单项 | 行为与条件 |
| --- | --- |
| 打开 | 使用默认路由；不可用时进入原因说明 |
| 打开方式… | 选择本机插件，支持仅此次/设为默认 |
| 添加到对话… | 选择当前对话或新对话，添加引用到草稿，不发送 |
| 复制资源 | 复制可跨插件的类型化资源引用，不复制文件字节 |
| 复制资源路径 | 复制 `电脑 / Workspace / mount / 目录 / 名称` 或本机逻辑位置的可读文本；不是 PC 绝对路径，不作为授权或执行参数 |
| 重命名 | 同一源端可写、在线且 provider 声明支持才启用；否则显示“此位置只读”等具体原因 |
| 另存副本到本机… | 显式下载并新建本机资源，展示大小、进度、取消和目标；保留来源关联但分配新身份 |
| 从最近移除 | 仅最近列表提供；移除记录可撤销，不删除源文件 |

“复制资源”和“复制资源路径”都保留，避免同一个 Copy 含义不清。首期不提供永久删除、剪切和跨源移动；不把“从最近移除”涂成删除文件的危险操作。

重命名先弹名称表单（保留扩展名、显示位置），检查重名/非法名称/源端权限；源端原子成功并返回稳定 ResourceRef/metadata receipt 后更新各处名称。冲突保留输入并给建议名；PC 掉线不可先乐观报告成功。只读引用和图片/视频等也遵从相同能力规则。

## 5. 跨插件复制与聊天引用

### 5.1 复制的是引用，粘贴显示为链接

- App 内 Resource Clipboard Broker 接受用户明确的复制/粘贴操作。引用包含作用域、稳定 refs、展示快照及可选 revision hint，不含可复用授权；它不是可直接读取内容的 capability。
- 系统剪贴板同时提供类型化表示和安全纯文本（名称 + 逻辑位置）；外部不支持该类型的 App 获得文本。只读写用户当次操作，不在启动、前台切换或后台轮询剪贴板。
- “复制资源路径”只写纯文本；支持资源引用的插件才把“复制资源”还原为卡片。不把任意纯文本或同名路径误识别成内部资源。
- 支持粘贴的插件声明引用接收能力；不支持时保持普通文本粘贴或提示可添加链接，不能静默转换成整文件上传。插件只经 Host 重新授权访问。
- 首期单资源操作；退出账号使内部剪贴板失效。粘贴来自其他账号、权限撤销、未知 provider 的引用均不能凭元数据取得访问权。

### 5.2 Tasks 的具体表现

1. 用户在资源菜单点“复制资源”，切到 Tasks，在对话框系统粘贴菜单/明确的“粘贴资源”入口粘贴；或者直接点“添加到对话…”选择目标。
2. 草稿中出现可点的紧凑卡片：类型图标 + 名称 + 来源 + 移除。文本草稿、光标和已加引用保留；卡片不把 URI 展开成一大串字符。最多 10 项，同一稳定引用/版本去重。
3. 加入草稿时重新 describe，固定一个 revision；内容已变化时显示可更新提示。发送前核验该版本和当前会话是否可授权，不存在“复制时已有权限，所以一直可读”。
4. 模型/任务不自动读取所有引用：发送前显示本次会交给任务的资源，依现有 Task/Agent 权限按 audience 单独发放读取权限。若需要向外部模型传内容，遵从任务数据地区与明确授权；无法解析引用时阻止该附件发送，保留文本和其他草稿，不仅靠一个隐形 URL 蒙混通过。
5. 发送后在消息中显示引用卡片，点击仍由统一路由在本机打开，返回保留会话与草稿；权限失效显示不可用。取消引用只修改草稿，不删除资源。首期不承诺外部浏览器可公开访问该链接。

对话卡片默认查看发送时实际使用的版本，另设“查看原件当前版本”。临时目录被清理后按源端/授权副本重新 materialize；源端离线且没有有效内容副本时，保留引用但明确暂不可打开。是否随对话长期保留附件副本需要独立的保留政策和授权，不默认为把手机文件上传 Cloud；仅保存版本号或元数据不算离线可用。此语义在 PC、手机与 Web 一致，handler 按当前点击端选择。

## 6. 右下 `+` 与插件贡献的新建

### 6.1 面板交互

点击 `+` 展开原生底部新建面板（不超过可视高度 88%，内容可滚动）：标题“新建”，右上关闭；保存位置行；**已安装插件提供的创建类型**两列网格；下方“导入文件 / 新建文件夹”基础动作。

面板是动作入口，不复刻 WPS 的 Office/在线文档/AI 多排硬编码分类。无创建贡献时显示“安装支持新建的插件后，会显示可创建的类型”，导入仍可用。空白 PDF、扫描、语音转文字等只有实际安装的插件明确贡献时出现。

- 最近分栏默认保存到本机 OpenMuse 资源目录；本机目录默认当前可写目录；PC 目录仅在写权限、源端 create 事务与该 creator 支持目标都满足时继承，否则位置行明确回到本机并解释原因，不静默写到其他电脑。
- 点创建类型后进入名称 + 位置表单，插件可选地声明少量、经过 schema 校验的创建参数。复杂模板/业务表单由插件页面承载，Host 不复制插件业务逻辑。
- 文件名建议来自插件的 defaultName/扩展名规范；Host 做重名与目录校验，不推断一个未知 MIME 应该用什么后缀。提交前最终名称、位置、创建插件可见。
- 提交显示创建中、取消/超时状态。以 idempotency key 执行，不因重试生成两份；成功 receipt 必须能 describe 新 ResourceRef，随后按路由打开。打开成功才进最近；创建成功但打开失败保留文件，按钮“重新打开”，不能重跑创建。
- 模板内容由插件生成；新资源的持久身份、目标授权、存储与提交边界归 Provider/Host 管。不能将现有 `createDraft(existingResourceRef)` 误称为“创建一个全新资源”的现成 API。

### 6.2 插件安装/卸载的变化

仅消费当前安装、收据/声明校验有效、启用、兼容 Mobile 的 creator。安装完成即刷新面板，不需重启；停用或卸载立即移除；正在填表时插件失效，保留名称/位置，明确提示后返回可用列表，不继续执行已撤销能力。

同一种类型由两个插件提供时各显示名称和提供者，不能覆盖彼此；创建排序建议本机偏好优先、其后本地化标题，禁止插件用任意 priority 抢占首位。未完成权限授权的入口可见但带理由，点入走明确授权。MCP `tools/list` 中任意名字含 create 的工具不能自动当创建贡献。

## 7. 视觉与可达性

## 8. 实施顺序与验收边界

1. 资源 Provider / 身份恢复、全局打开事件与最近索引；本机授权适配。先验证同名跨源、迁移引用和不泄露物理路径。
2. Home 五栏导航、最近/本机/PC 层级、统一打开与打开方式；接通取消、离线、权限错误及原有任务草稿恢复。
3. 剪贴板 Broker + Tasks 引用草稿 + 独立授权；本机/PC 重命名契约与回执。UI 能力状态必须来自 Provider。
4. creator 贡献、源端 create 事务、动态安装/停用、幂等与失败恢复；完成后才能开放首期新建类型。
5. 两端真机、中英文、浅深色、长文件名、320px 与大字、低网速/离线验收；不以原型模拟代替生产能力验收。

P0 必测：成功打开去重；失败不计最近；PC 重连不复用过期 nodeRef；同名不同来源；切换账号；重命名冲突与失败；复制引用不带 grant；粘贴不自动发送；聊天 consumer 重新授权；插件卸载默认打开失效；creator 动态变化；创建重试只一份；创建成功打开失败不重建；大文件可取消；无 handler、无创建器、空/错/加载；目录返回/滚动状态；双端安全区和大字。
