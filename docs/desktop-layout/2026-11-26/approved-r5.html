审阅说明与验收范围
设计原型使用模拟数据，未连接文件系统、账号或模型。左侧图标可点击：同项收起、异项替换；侧栏中的内容可在右侧打开；支持宽度拖动、⌘/Ctrl+B、⌘/Ctrl+Shift+E、浅深主题、中英文与故障恢复。Explorer 项使用目录展开，不以目录点击代替业务命令。所有窗口均使用占位侧栏，展开向右推、收起向左回填；小于 900 时主区改为 Agent / 工作区分段视图，保持各自状态。共享工作区已并入 Explorer；Search、Outline 和 Timeline 不作为独立能力出现。Mobile 与独立 Web 产品不在本版改造范围。
仅 Agent 主区槽位固定：收起侧栏时主区可整体左移，Agent 宽度及会话实例不变；右侧插件不能与其交换。设置位于左下角；Esc 关闭菜单与插件市场，键盘焦点返回来源入口。参考 VS Code 的导航关系，沿用 Muse 配色与字体。图标统一使用 Phosphor Icons 2.1.1（MIT），保留系统字体，无远程依赖。
