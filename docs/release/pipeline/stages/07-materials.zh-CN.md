# 07-materials · 演示资源与商店物料

负责人：产品、设计与发布负责人。状态与证据单独保存在每次发布的 `stages/07-materials.json`。

## 输入与目标

每个商店保留独立素材与字段，公共资源复用且标注来源。

前置节点：03-privacy、06-binary。

## 执行步骤

- 准备 1024 图标、Play 图标/feature graphic、手机/iPhone/iPad 对应截图；截图尺寸以提交当日平台要求为准。
- 优先实际普通 App 真机截图；模拟器/QA 截图分别标记。若仅元数据变更复用截图，写清原始构建和复用理由，不能改写来源为新包。
- Home Recent 随包包含 OpenMuse User Guide.sydoc、Introduction.pptx，指南包含真实截图和 HTTPS 超链接；VPS 的授权演示目录放同版资源。
- 维护英文名称、副标题、短/长描述、支持/隐私/删除 URL、年龄与内容权利、出口合规、审核步骤。
- 审核账号密码仅写商店私有审核表或密钥库；物料里只放账号角色、使用步骤和凭据引用，不能存明文密码。
- 检查登录不依赖审核员无法完成的验证码，Desktop 在线，演示文件可用。

## 输出与验收

渠道素材目录、逐图 provenance/SHA-256、英文字段 JSON、审核说明、图文指南/演示稿、私有表已保存的记录。

证据不足保持 partial/pending；通过后由负责人填写 passed、owner 和 evidence。后续修改使本节点结论失效时，重新打开相关节点。
