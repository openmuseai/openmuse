# 国内 Android 和中国区 iOS

复用 12 阶段，国内渠道另开 lane 与回执；没有该渠道的证据就保持未完成。通用 Android 仍为 `com.openmuseai.mobile`，iOS 同 Bundle ID。应用宝、华为 Android、小米、OPPO、vivo 等按各自实际控制台要求核验。

- 国内 Android 使用 `build-android-store.sh --lane cn`，正式签名 APK 可在要求一致的市场复用；渠道 SDK、代签、功能或服务端差异才单独构建，并另存版本、哈希、签名、升级测试及 SDK 申报。
- 中国区 iOS 使用对应中文/国内服务配置；同一个 ASC 版本只能提交一份二进制，跨地区能力差异先完成产品及合规设计再决定发行策略。
- APP 备案号、主体、名称、域名、包名和正式签名应相符。网站 ICP 号不能代填 APP 备案号；占位编号不用于正式提交。
- 复核首次协议、权限申请时机、SDK 与数据清单、注销删除、反馈/举报、中文政策与服务路由；新增服务内容需要重新评估相应资质。
- 每个市场保存截图规格、测试设备/ABI、包格式、隐私自查、资质文件提交位置及审核/发布记录；不要宣称海外审核通过意味着国内自动合格。

详细历史字段见 `app/openmuse_mobile/release_materials/README.zh-CN.md` 与同目录备案材料；含主体证照、联系人和密钥的原件放公司受控资料库，本流水线只索引其引用。
