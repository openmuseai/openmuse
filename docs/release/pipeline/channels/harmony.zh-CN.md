# HarmonyOS 渠道

鸿蒙原生包名为 `com.openmuseai.hm`，与 Android/iOS 不同且不可互换证书。已有 APP ID、发布证书和 Profile 的登记记录不等于已有可上架产品。

1. 确认 HarmonyOS 工程与本期需求；实现登录、文档、同步、协议、权限、删除和错误处理。
2. 用 DevEco 与华为当前工具链构建控制台接受的 APP/HAP，使用原鸿蒙正式证书/Profile 并验签。
3. 后台所选手机、平板、PC/2in1、智慧屏、手表等每类设备分别适配和验收；未支持的类别在提交前调整范围。
4. 核对 APP 备案、权限/SDK、中文政策、资源、图标和各设备截图。
5. 在 AppGallery Connect 完成测试、审核、获批、发布及公开安装验证，独立保存回执。

当前首发档案没有鸿蒙功能/真机/正式包的完成证据，不能复制海外 iOS 或 Android 的 passed 状态。
