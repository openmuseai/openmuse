# Mobile 界面整改与验收

日期：2026-10-31。版本 `1.0.0 (6)`，美区内部候选。本轮 Mobile 界面和本地语音模型管理已通过两端模拟器及物理设备验收；此前真实账号、Linux 联动和账号删除结果见 [2026-10-30 记录](14-全球化移动验收-2026-10-30.zh-CN.md)。本轮不重复删除活动账号，不上传商店。

## 界面结果

采用仓库 [design-taste-frontend-v1](../../../.agents/skills/design-taste-frontend-v1/SKILL.md) 的应用界面原则，在既有 Flutter 组件和蓝色品牌色上统一留白、字号、分组、浅深色对比度。用户第一张附件实际为旧 Web 设置截图，Discover 部分按其文字要求实施。

| 用户要求 | 实施结果 |
| --- | --- |
| Discover / My Plugins 同行 | 标题栏保持一行，空间不足时适度缩字，支持横向滑动；移除 Featured / Office / UI / Coding 分类及 Desktop plugins 区域 |
| Store provider 移至 Account | 独立商店源设置页，保留真实源选择、自定义 HTTPS 地址校验及本地持久化；嵌入式 Discover 不再显示源控件 |
| 首页按钮及导航对比度 | 菜单图标和语音按钮使用成对主题前景/背景；发送的可用和禁用状态清晰；Tasks 改为空心，Discover 使用指南针，Account 使用人物轮廓 |
| 语音模型安装 | 缺少模型时显示含“下载模型”的底部面板，一次点击开始下载并进入管理页；Account 增加同一管理入口，可看进度、取消、重试、删除 |
| Account 整理 | 头像账号行进入详情页；退出登录和底部注销入口仅在详情页；移除 My plugins、Text size、Devices and workspaces |
| 语言与版本 | Language 使用单行标题及独立选择页，支持跟随系统；About OpenMuse 下方和关于页读取真实版本/构建号 |

My Plugins 内的 All / Enabled / Disabled / Updates 安装状态筛选保留；移除的是 Discover 的内容分类条。账号头像使用当前邮箱首字母，详情展示真实可用邮箱；没有复制参考图中不存在的昵称、手机号数据。删除仍使用既有二次确认和异步失败处理。

## 本地语音模型

此处是离线普通话语音识别（ASR）模型，不是对话大模型；页面明确语言范围，不声称支持英语识别。四个文件合计 **30,975,688 字节**，下载前固定大小和 SHA-256，全部校验完成后才从临时目录移入模型目录。取消和失败清理临时下载；移除前卸载识别引擎，只删除该模型的四个已知文件，保留其他用户文件。

- 上游：`csukuangfj/sherpa-onnx-streaming-zipformer-zh-14M-2023-02-23`。
- 固定修订：`204ad334e2e683fd295359930cc16fc0432a23ac`；上游标注 Apache-2.0。
- 美国资源镜像：`https://us.openmuseai.com/resources/speech/<modelId>/<revision>/<file>`，保留来源说明、许可证及摘要清单，未修改 Nginx 配置。
- 客户端按当前区域 Cloud origin 取资源；本轮仅部署、验收美国路径，中国资源路径未作可用性承诺。
- 摘要、尺寸及来源：`target/mobile-acceptance/2026-10-31/speech-source.json`。模型按需下载，不打入 APK/AAB/IPA；不需要账号密钥。
