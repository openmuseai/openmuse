# OpenMuse 单次移动应用发布记录模板

每次发布复制此模板到**公司受控发布系统**，由实际执行人填写；备案查询截图、测试账号、隐私评估和商店后台截图存受控位置，只在此记录证据链接。不要把密码、私钥、证件号码或审核账号写入公开仓库。

## 发布范围

| 字段 | 本次填写 |
| --- | --- |
| 发行负责人 / 值班人 / 日期 | 待填 |
| Git commit / tag / 源码仓库 | 待填 |
| 版本名 / Android versionCode / iOS build / Harmony versionCode | 待填；各渠道递增 |
| 上线国家/地区与商店 | 待填；中国 Android 各市场、中国区 App Store、海外 App Store、Google Play、HarmonyOS 逐一列出 |
| 本次功能与收费/插件/SDK/权限/域名变更 | 待填 |
| APP 备案号及查询记录 | 待填；与网站备案号区分 |
| 地区法规/资质审查负责人及结论 | 待填 |
