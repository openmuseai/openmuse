# 隐私、权限与商店问卷底稿

这是根据源代码和现有网站隐私政策整理的**初稿**，不是已完成的 Apple 隐私标签或国内市场 SDK 清单。发布包的传输、第三方 SDK、服务器保留规则必须由运营与开发共同确认。

## 已见数据流

| 数据 / 权限 | 用途与源代码证据 | 待核对的申报点 |
| --- | --- | --- |
| 邮箱、账号 ID、会话凭证 | 注册登录、保持会话；`lib/main.dart` 创建 GoTrue 认证，`PrivacyInfo.xcprivacy` 声明 EmailAddress/UserID | Apple“关联到用户 / App 功能”；国内政策写明处理者、目的、保存期限及联系渠道 |
| 本机随机设备 ID | `lib/main.dart` 的 `_persistentMobileDeviceId`，用于设备登记和配对；iOS 隐私清单申报 DeviceID | 核对 Apple 对自生成 ID 的分类、是否用于跟踪；当前配置宣称不跟踪 |
| 文档、工作空间与消息 | 用户打开文件、云端同步或向配对 Desktop 发送；iOS 隐私清单申报 OtherUserContent | 核对哪些内容上传、接收方、保存与删除方式；尤其检查插件访问范围 |
| 麦克风/语音 | Android `RECORD_AUDIO`，iOS `NSMicrophoneUsageDescription`；界面说明本机识别 | 真机验证录音不上传、权限拒绝后仍能用其他功能；隐私政策中如实说明 |
| 网络、诊断及更新 | `lib/main.dart` 的云端/插件市场端点及应用更新检查 | 核实服务器日志、IP、崩溃/诊断数据、第三方依赖的数据收集，不能只按 Manifest 判断 |
| 文件选择与本地存储 | `file_picker` 与文档功能 | 检查最终合并 Manifest、iOS 权限弹窗和临时文件清理 |

## 官方问卷填写原则

- Apple App Privacy：按**发布版实际数据流**逐项确定“收集”“关联用户”“跟踪”“用途”，包含第三方 SDK。工程的 `PrivacyInfo.xcprivacy` 是线索，不能直接替代 App Store Connect 问卷。Apple 要求链接可访问的隐私政策。
- 国内 Android 市场：准备《个人信息处理规则》、权限用途、第三方 SDK 名称/提供方/目的/方式/数据类型、账号注销方式；用实际发布包的依赖与运行网络请求逐项核验。
- 鸿蒙：当前 `../../openmuse_harmony` 仅有本地原生入口页，尚未接入登录或网络服务。完成功能移植后，须以正式 HAP 的权限、SDK 与实际数据流重新填写华为隐私及备案问卷，不能直接沿用 Android/iOS 草稿。
- 网站政策源位于 `Muse-WebSite/lib/legal.ts`，移动端按语言链接到 `https://openmuseai.com/zh/privacy` 或 `/en/privacy`；已有公开的 `/zh/account-deletion` 和 `/en/account-deletion` 页面。提交 Google Play Data safety 和账号删除声明前，仍须用正式候选包和专用账号实测应用内删除入口、网页请求路径及后端删除结果，不能仅凭页面存在就宣称流程通过。
- 主办方提供的运营主体为“东莞市成宣电子科技有限公司”，公开邮箱为 `developer@openmuseai.com`。2026-10-28 已在中英文隐私政策中列明，并新建支持和账户删除页面；商店问卷仍须按发布版实际数据流复核。
- 插件市场可能展示或下载额外内容。iOS 上架前须核对 [Apple 2.5.2 与 4.7](https://developer.apple.com/app-store/review/guidelines/) 对可下载功能、插件目录、内容管理与隐私同意的要求；审核说明须准确描述真实能力。
