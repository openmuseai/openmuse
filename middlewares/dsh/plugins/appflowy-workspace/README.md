# AppFlowy Workspace Plugin

Logical Plugin `muse.appflowy.workspace`. Pins a DSH cwd (README only), lists AppFlowy folder views from the Host sidebar catalog (P0) or Cloud folder collab (P1) via `muse_workspace_list_views`, and never treats the DSH working directory as the page tree.

See [TECH.zh-CN.md](TECH.zh-CN.md).
