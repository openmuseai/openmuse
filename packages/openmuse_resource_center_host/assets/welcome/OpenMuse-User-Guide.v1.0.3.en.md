# OpenMuse / Office Harness 1.0.3 Guide

Smart Documents, presentations and connected tasks. Office Harness is the iOS App Store name; OpenMuse is used on Android. Keep your own documents separate from these practice files.

Edition: 25 November 2026 · United States service · English

## 1. Start with the right version

1.0.3 includes native Smart Documents, the bundled presentation editor and optional local task-result reminders. Use the [official download page](https://openmuseai.com/en). Capabilities depend on your device and the active connection.

## 2. Find your way around

Home contains your workspace and recent activity. Tasks lists connected work; Apps contains available applications; Mine contains account and settings. Read the [online guide](https://us.openmuseai.com/en/guide/) if you need more context.

```text
Home → open a resource → edit → save/checkpoint → reopen the same resource
```

## 3. Create a Smart Document

Open your workspace resources and use the available creation action. Choose Smart Document and give the file a useful name. New native documents use the Smart Document format. See the [resource guide](https://us.openmuseai.com/en/guide/).

## 4. Edit carefully

Tap a paragraph to place the caret. Use the editor's available heading, list and formatting controls. On a phone, keep the caret above the keyboard and scroll the document when needed. For inaccessible controls, contact [support](https://us.openmuseai.com/en/support/) with the app version and device model.

## 5. Save, close and reopen

Let the current save or checkpoint finish before leaving. Reopen the same file and confirm your change. If saving fails, keep the draft and use the available retry or recovery action. A local checkpoint does not prove cloud synchronization. Check the [guide](https://us.openmuseai.com/en/guide/) before replacing a file.

## 6. Local and connected locations

Check the selected account, service region and workspace before opening a file. A connected location can become unavailable when its computer goes offline. Keep important originals and backups. The [privacy policy](https://us.openmuseai.com/en/privacy/) explains service data handling.

## 7. Presentations on a phone

Open the sample OpenMuse Introduction.pptx, select a slide and edit a short text box. Use Save, close and reopen to verify the file. The ribbon can scroll horizontally on a narrow display. Report reproducible editing failures through [support](https://us.openmuseai.com/en/support/).

## 8. Imports and original files

Use the system picker to select the intended file only. An imported managed copy may be separate from the external original. Keep both until you have checked the result. Review the [terms](https://us.openmuseai.com/en/terms/) before using third-party content.

## 9. Connect a computer for tasks

Keep your computer and Desktop app running. Use the same account and service region, then authorize the connection and intended workspace. Login alone does not authorize every folder. Follow the [connection guide](https://us.openmuseai.com/en/guide/).

```text
Choose account + region → authorize a computer → select its workspace → run a task
```

## 10. Review AI sharing before sending

Review the recipient, model and data categories shown before sending. Cancel if you do not want to share. Context and authorized workspace resources can be included in a task. Cancelling later cannot recall already-transmitted data. Read the [privacy policy](https://us.openmuseai.com/en/privacy/).

## 11. Turn on optional task reminders

In Mine, open Notifications and enable Task result reminders. Read the explanation, then choose whether to allow the system permission. The app preference and system permission are separate. Reminders use generic success/failure text with no document content. For help, use [support](https://us.openmuseai.com/en/support/).

```text
Mine → Notifications → enable reminders → system permission → task result reminder
```

## 12. Understand reminder limits

The app must be running and receiving results. Results may not arrive after the app is closed. This version does not use remote push. Tapping a reminder opens the current account's task list. If system permission is off, use the displayed system-settings action. See the [guide](https://us.openmuseai.com/en/guide/).

## 13. Account, region and language

Use the intended service region on each device. Display language does not move your account or documents. Signing out or changing region ends the old active context. Review the [privacy policy](https://us.openmuseai.com/en/privacy/) and [account-deletion information](https://us.openmuseai.com/en/account-deletion/).

## 14. Upgrading from older plugins

Legacy downloaded plugins are unavailable in this release. Their installation records, directories and user files are retained. A retained older guide remains a separate original; this Smart Document guide does not overwrite it. Contact [support](https://us.openmuseai.com/en/support/) if you need help exporting an older file.

## 15. Offline and recovery

Offline content can be readable while edits or uploads are pending. Reconnect and check the real status before assuming synchronization succeeded. Never delete the only copy to dismiss an error. Follow the [guide](https://us.openmuseai.com/en/guide/) and keep a separate backup.

## 16. Reports and support

Include the app version, device model, visible error and minimal reproduction steps. Do not send passwords, private document text or one-time codes. Use [support](https://us.openmuseai.com/en/support/) and consult the [terms](https://us.openmuseai.com/en/terms/) and [privacy policy](https://us.openmuseai.com/en/privacy/).
