# OpenMuse / Office Harness 1.0.3 使用指南

智能文档、演示文稿与连接电脑运行的任务。iOS App Store 名称为 Office Harness，Android 使用 OpenMuse。请将个人重要文件与练习文件区分保存。

版本：2026年11月25日 · 中国大陆服务 · 简体中文

## 1. 从正确版本开始

1.0.3 包含原生智能文档、内置演示文稿编辑器以及可选的本地任务结果提醒。请通过[官方网站](https://openmuseai.com/zh)提供的渠道安装。可用能力以设备和当前连接为准。

## 2. 认识主要入口

首页展示工作空间及最近活动；任务用于连接电脑后的工作；应用展示可用应用；我的包含账号和设置。遇到问题可查看[使用帮助](https://openmuseai.com/zh/support)。

```text
首页 → 打开资源 → 编辑 → 保存或建立检查点 → 重开同一资源
```

## 3. 新建智能文档

进入工作空间资源，使用当前可用的新建操作，选择智能文档并填写名称。新文档使用原生智能文档格式。需要帮助时联系[支持](https://openmuseai.com/zh/support)。

## 4. 编辑与键盘

点按段落放置光标，通过编辑器现有控件设置标题、列表和文字格式。手机上请保持光标可见，并滚动文档避开键盘。控件不可用时，向[支持](https://openmuseai.com/zh/support)提供版本和设备型号。

## 5. 保存、关闭与重开

离开前等待当前保存或检查点结束，再重开同一文件确认内容。保存失败时保留草稿，使用重试或恢复操作；本地保存不代表云端同步完成。处理重要内容前请了解[服务条款](https://openmuseai.com/zh/terms)。

## 6. 本地与连接位置

打开文件前核对当前账号、服务地区和工作空间。电脑离线时，连接位置可能不可用。重要原件应另行备份。数据处理方式见[隐私政策](https://openmuseai.com/zh/privacy)。

## 7. 手机编辑演示文稿

打开练习文件 OpenMuse Introduction.pptx，选择幻灯片并修改一小段文字。使用保存，退出后重开确认。窄屏上的工具栏可以横向滚动。编辑故障请通过[支持](https://openmuseai.com/zh/support)反馈重现步骤。

## 8. 导入与原件

通过系统文件选择器只选择需要的文件。导入后的管理副本可能与外部原件分开保存，确认结果前请同时保留。使用第三方资料时遵守[服务条款](https://openmuseai.com/zh/terms)及相应权利要求。

## 9. 连接电脑运行任务

保持电脑和 Desktop 应用运行。在手机和电脑上使用相同账号及服务地区，授权连接并选择所需工作空间。登录并不自动授权全部文件夹。连接问题可联系[支持](https://openmuseai.com/zh/support)。

```text
选择账号与地区 → 授权连接电脑 → 选择工作空间 → 运行任务
```

## 10. 发送前核对 AI 数据共享

发送前核对界面显示的接收方、模型和数据种类。不愿共享时选择取消。任务可能包含上下文和已授权工作空间资源；事后取消无法召回已传输数据。详细说明见[隐私政策](https://openmuseai.com/zh/privacy)。

## 11. 开启可选任务提醒

在我的中打开通知，开启任务结果提醒，阅读用途说明后自行决定是否允许系统权限。应用偏好与系统授权分别显示。提醒仅使用通用成功或失败文案，不包含文档正文。设置问题可联系[支持](https://openmuseai.com/zh/support)。

```text
我的 → 通知 → 开启任务提醒 → 允许系统权限 → 接收任务结果提醒
```

## 12. 了解通知边界

应用必须运行并收到任务结果；关闭应用后可能无法收到结果。此版本不使用远程推送。点击提醒进入当前账号的任务列表。系统权限关闭时可使用界面的系统设置入口。需要帮助请联系[支持](https://openmuseai.com/zh/support)。

## 13. 账号、地区与语言

在各设备上选择预期的服务地区。切换显示语言不会迁移账号或文档。退出账号、切换地区会结束旧的活动上下文。请查看[隐私政策](https://openmuseai.com/zh/privacy)及[账号注销说明](https://openmuseai.com/zh/account-deletion)。

## 14. 从旧插件升级

此发行版无法运行旧版下载插件，但保留其安装记录、目录和用户文件。新版指南使用独立的智能文档资源，不覆写保留的旧指南。需要导出旧文件时请联系[支持](https://openmuseai.com/zh/support)。

## 15. 离线与恢复

离线时可读内容不代表全部编辑或上传已经完成。重连后核实真实状态，不要为了清除报错而删除唯一副本。重要资料应另行备份；故障可向[支持](https://openmuseai.com/zh/support)反馈。

## 16. 反馈与服务信息

请提供版本、设备型号、可见错误和最小重现步骤，不要发送密码、私人文档正文或验证码。可查看[官方网站](https://openmuseai.com/zh)、[服务条款](https://openmuseai.com/zh/terms)、[隐私政策](https://openmuseai.com/zh/privacy)，或联系[支持](https://openmuseai.com/zh/support)。
